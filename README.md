## Sobre a disciplina

A disciplina de Laboratório de Programação tem como objetivo introduzir e consolidar conceitos fundamentais de programação, com foco principalmente em **Programação Orientada a Objetos (POO)** utilizando **Java**.

Durante a disciplina, são abordados conceitos importantes para o desenvolvimento de aplicações modernas, relacionando a teoria com exemplos e projetos práticos.

Entre os principais tópicos estão:

* Programação Orientada a Objetos (POO)
* Java e seus principais recursos
* Classes, objetos, atributos e métodos
* Encapsulamento, herança e polimorfismo
* Desenvolvimento de aplicações web
* Introdução a frameworks modernos, como Spring Boot
* HTML e CSS
* JavaScript e tecnologias relacionadas
* React Native
* Desenvolvimento de aplicações e interfaces
* Integração entre diferentes tecnologias

As atividades deste repositório reúnem exercícios e projetos desenvolvidos ao longo da disciplina, utilizando diferentes tecnologias e linguagens voltadas para programação, desenvolvimento web e aplicações modernas.

## Tecnologias

As principais tecnologias utilizadas na disciplina incluem:

* Java
* Spring Boot
* HTML
* CSS
* JavaScript
* React Native
* Git e GitHub

## Como executar

Os projetos podem possuir diferentes formas de execução dependendo da tecnologia utilizada. Para projetos Java, é necessário ter o **JDK** instalado. Projetos web e React Native podem exigir ferramentas adicionais, como **Node.js** e gerenciadores de pacotes.

Consulte as instruções específicas de cada atividade ou projeto para obter os comandos necessários para execução.
